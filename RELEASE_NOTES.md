## Bifrost 1.9.7

- Admins can share a mod's settings with players: Mods → ⚙ → **Players get the settings of this file too**. Some settings are not sent by the server because the game of the player standing next to a creature works them out - e.g. OdinHorse's taming time and food: a friend taming a horse used his own default 1600 seconds. With the switch on, the settings you changed from the defaults go into the server's list and every player's Bifrost writes them into that player's config on PLAY, before the game starts. The rest of their file (key binds, UI) stays theirs; turning the switch off puts what Bifrost wrote back to the defaults.
- Players need Bifrost 1.9.7 for it (it updates itself).
- 1.9.6: optional password in the server list, fresher direct-join address. 1.9.5: config edits survive a server restart.
