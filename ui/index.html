Nexus Mods

        
Pentru modurile care nu sunt pe Thunderstore. Cheia ta personală: nexusmods.com → Settings → API Keys (jos, „Personal API Key”). Cu cont gratuit apeși „Mod Manager Download” pe site pentru fiecare fișier și Bifrost îl instalează; cu Premium e complet automat. Cheia e salvată criptat cu contul tău Windows.
